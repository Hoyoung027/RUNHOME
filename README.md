# RunHome

한국 프로야구 팬을 위한 개인화 webOS 홈화면 프로젝트입니다.

사용자가 선호하는 KBO 구단을 선택하면 구단 로고, 대표 색상, 경기 정보, 뉴스, 시청 앱 바로가기 등을 반영한 맞춤형 홈화면을 제공합니다.

## 주요 기능

- 사용자 로그인
- 선호 KBO 구단 선택 및 변경
- 구단별 홈화면 커스터마이징
- 경기 일정, 실시간 스코어, 주요 스탯 표시
- 관련 뉴스 요약 및 시청 앱 바로가기
- 시계, 날씨, 시스템 자원 현황 표시
